{% comment %} Mermaid diagram rendering. Loaded by the layout only when a page sets `mermaid: true` in its front matter, so the ~300KB module is fetched by the handful of pages that draw diagrams and by nothing else. --- layout: default title: Architecture mermaid: true --- Then write diagrams as ~~~mermaid fences. Two things this has to do that a plain Mermaid include does not: 1. **Unwrap the code block.** kramdown turns a ~~~mermaid fence into an element carrying the "language-mermaid" class: a
under Rouge, a bare without a highlighter. Mermaid wants a
holding the raw text, so either form is converted before it initialises. Left alone, the diagram source renders as literal text in a code block. 2. **Follow the page theme.** Mermaid picks its palette once at init and cannot read the CSS custom properties, so the theme has to be resolved here, in the same three states the stylesheet uses: an explicit data-theme stamp in either direction, and otherwise the OS preference. Hard-coding "neutral" leaves a white diagram glowing on the dark ground. {% endcomment %}
